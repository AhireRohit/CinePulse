https://image.tmdb.org/t/p/w1280/tmU7GeKVybMWFButWEGl2M4GeiP.jpg

Movie posters use the existing catalog's IMDb/Amazon URLs, requested at an appropriate image size. Films without available artwork use a typographic fallback; no generated art is presented as an actual film poster.
